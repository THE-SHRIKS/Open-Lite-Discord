# SIDEBAND Visual & Screenshot Review (`docs/SCREENSHOT_REVIEW.md`)

## 1. Visual System Compliance (`design/VISUAL_DIRECTION.md`)

All UI surfaces were built from scratch using the SIDEBAND design token system (`apps/web/src/styles/tokens.css`, `apps/web/src/styles/app.css`):

| Token | Value | Application |
|---|---|---|
| `--canvas` | `#0B0D0E` | Primary background canvas (deep graphite) |
| `--surface-0` | `#101416` | 76px workspace rail |
| `--surface-1` | `#151A1C` | 244px channel navigation & 264px member sidebar |
| `--surface-2` | `#1B2224` | Active channel fill & message hover state |
| `--surface-raised` | `#222B2D` | Modals, dialogs, code blocks, elevated controls |
| `--stroke` | `#303B3E` | 1px structural borders and panel dividers |
| `--stroke-emphasis` | `#526163` | Active input borders and scrollbars |
| `--type` | `#E9ECE7` | Primary high-legibility typography |
| `--type-muted` | `#9FAAA6` | Secondary metadata and descriptions |
| `--type-faint` | `#74827E` | Timestamps, sequence numbers, tombstones |
| `--signal` | `#A0BF9F` | Mint-olive signal accent for active indicators, focus rings, and online status |

### Guardrail Verification
- **Zero External Fonts or Assets:** Uses local platform font stack (`"Segoe UI Variable", "Inter", system-ui, sans-serif`) and bundled custom SVG glyph (`SidebandIcon.tsx`).
- **Original Identity:** Rectangular space badges (`iconText` in sturdy geometric typography with left `--signal` bar), editorial left-aligned message clusters with sequence tags (`#1`, `#2`), and monolithic bottom composer.
- **No Forbidden Patterns:** Zero gradients, zero neon glows, zero glassmorphism, zero copied Discord assets/mascots.

## 3. Rubric Self-Check (Human Sign-Off Required for Phase Gates)

| Criterion | Verified Evidence |
|---|---|
| Authored visual identity | Custom geometric glyph, dark graphite/mint-olive palette, 1px strokes |
| Readability & hierarchy | 14px UI body, 15px/1.6 message body, clear sequence/timestamp metadata |
